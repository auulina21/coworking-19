# Швидка перевірка
Див. README для команди поточного етапу.
1. Запустити й перевірити всі чотири бізнес-сценарії прототипу.
2. Відхилити end<=start, дубль id і перетин для одного місця; суміжні інтервали й різні місця прийняти.
3. Перевірити відмову рахунку до підтвердження та змін після підтвердження.
4. Етап 003: відкрити нове з'єднання, звірити таблицю й експорт HTML з даними БД.
5. Етап 004: додати, виправити, видалити через браузер; перевірити 400/404/409, перечитати дані після перезапуску.
