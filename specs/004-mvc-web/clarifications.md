# Уточнення
Рішення прийняв Codex у межах доручення налаштувати все самостійно.
1. Час локальний ISO, [start,end), суміжні інтервали дозволені.
2. Порівняння місць після trim, без урахування регістру.
3. Ідентифікатор незмінний; видалення частини прибирає лише відповідний інтервал.
4. Сховище є джерелом істини. Відмова не змінює колекцію.
5. Модель не Singleton. Для вебсесії початковий стан DRAFT; без автоматичного наповнення.
